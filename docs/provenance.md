# Provenance

This standalone edition is maintained by Yousef Mousa (`Robertsvg`). It is
based on the local integrated Kritzel application at revision
`adbd8c3` (`integration/all-group-features`, 1 August 2026), including the
working-tree source present when this edition was prepared.

The original application repository is
<https://git.digitalelehre.org/Kritzel/app>. It uses UIX and DATEX from unyt
and includes collaborative work by the TU Berlin Kritzel team. The original
repository remains the reference for the complete author and commit history.

This distribution keeps the merged application features while removing
contribution-marker comments, obsolete schedule models, task allocations,
submission documents, development logs, and generated runtime state. Existing
utility and framework copyright notices remain intact.

The portfolio changes add reproducible configuration, documentation, automated
checks, and regression fixes.
